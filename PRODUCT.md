# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Pixeltable Cloud for the catalog and search service, as selected by the founder.
Vercel for the website and credential-protecting search route. Next.js with
TypeScript is the implementation choice for the shared frontend and gateway.
The existing Go skill remains a separate Apache-2.0 project.

## Users

People asking an agent to do work without knowing which specialist skills exist.
The website lets them explore useful capabilities and install AgentForge.

## Product Purpose

Translate an ordinary task into useful skill recommendations. Maintain the
index, provenance, and retrieval rather than editing third-party skills.

## Capabilities and Constraints

One search contract serves the website and installed skill. Source URLs and
revisions are real. Unknown compatibility is labeled. No fabricated social
proof, completeness claims, or benchmark claims. Platform code is proprietary.
Cloud credentials remain server-side. No paid hosting add-ons or plan upgrades.

The approved brand direction is a literary field guide with warm ivory,
forest green, restrained gold, an inscription-like treatment of the complete
founder tagline, and an original two-ring forge emblem. Keep search and
installation controls familiar and readable. The literary font is self-hosted.
The platform and website remain proprietary, with the bundled font under its
own SIL Open Font License.

## Evidence on Hand

The company PRD is the approved build brief. No hosted catalog or user outcomes
were measured before this implementation. Deployment targets are being confirmed.

## Accessibility & Inclusion

Keyboard search, clear focus, status announcements, and responsive operation
at 360 pixels. Respect reduced motion.
