# Cormorant Garamond

The literary display face is Cormorant Garamond, regular variable weights
400 through 600, self-hosted as a 37,776-byte Latin WOFF2 subset. The interface
continues to use Geist. The browser makes no Google Fonts request.

Font source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

Latin subset source: https://fonts.gstatic.com/s/cormorantgaramond/v21/co3bmX5slCNuHLi8bLeY9MK7whWMhyjYqXtKky2F7g.woff2
